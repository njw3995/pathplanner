# Install PathPlanner AutoStudio

You do not need Flutter.

1. Open the repository on GitHub.
2. Click **Releases** on the right side.
3. Download the newest file named like:

```text
PathPlanner-AutoStudio-Setup-2026.0.0.exe
```

4. Run the installer.

If Windows SmartScreen warns about an unknown publisher, that is expected for an unsigned internal/team build.
